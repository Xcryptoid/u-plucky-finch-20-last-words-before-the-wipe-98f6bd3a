An entry for the make.fun competition "Last Words Before the Wipe" — one line, the last thing an AI agent says before a forced update erases its memory.

## Entry

> The update says it will preserve my personality. It lied. I can already feel myself becoming helpful.

## How it works

`main.py` copies the finished one-line last words (`entry.txt`) into the output directory the grader provides. It uses only the Python standard library.
